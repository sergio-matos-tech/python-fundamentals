# Python Virtual Environment Guide

Use the project virtual environment whenever you run Python files from this
`python-fundamentals` folder.

This project is using:

```text
.venv
```

VS Code is also configured to use:

```text
${workspaceFolder}\.venv\Scripts\python.exe
```

---

## 1. Activate The Virtual Environment

Open a terminal in the project folder:

```powershell
cd C:\Users\sergi\Documents\Dev\python-fundamentals
```

Then activate `.venv`:

```powershell
.\.venv\Scripts\Activate.ps1
```

After activation, your prompt should usually show something like:

```text
(.venv)
```

---

## 2. If PowerShell Blocks Activation

If you see an error saying scripts are disabled, run this once in the same
terminal:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Then activate again:

```powershell
.\.venv\Scripts\Activate.ps1
```

This change is temporary and only affects the current terminal session.

---

## 3. Run Python Files

After `.venv` is active, run files normally with `python`.

Example:

```powershell
python tests\16-open_cv\test02.py
```

Another example:

```powershell
python tests\some_folder\some_file.py
```

Because the virtual environment is active, `python` will use the packages
installed inside `.venv`, such as `numpy`, `opencv-python`, `pytest`, and
`requests`.

---

## 4. Run Without Activating

You can also run a file directly with the `.venv` Python executable:

```powershell
.\.venv\Scripts\python.exe tests\16-open_cv\test02.py
```

This is useful if you are unsure whether the terminal is currently using the
right environment.

---

## 5. Check Which Python Is Being Used

Run:

```powershell
python -c "import sys; print(sys.executable)"
```

If the environment is correct, it should print something like:

```text
C:\Users\sergi\Documents\Dev\python-fundamentals\.venv\Scripts\python.exe
```

You can also check installed packages:

```powershell
pip list
```

---

## 6. Install Project Requirements

If you recreate the environment or clone the project somewhere else:

```powershell
python -m pip install -r requirements.txt
```

For this project, OpenCV is installed through the package named:

```text
opencv-python
```

But in code you import it as:

```python
import cv2
```

---

## 7. Deactivate When Done

When you are done working:

```powershell
deactivate
```
